# Cases & Support

Cases turn customer issues into tracked, resolvable work.

## Cases

A **case** records a customer problem or request — subject, description,
priority, status, and the related contact/account. Cases give support work a
single home alongside the rest of the customer relationship, so the people
handling a ticket can see the full context.

## Queue board

The **case queue board** presents open cases in a board layout so a team can see
what's waiting, what's in progress, and what's resolved at a glance, and pick up
work without stepping on each other.

## Comment threads

Each case has a **comment thread** for the running conversation and internal
notes, keeping the resolution history attached to the case rather than scattered
across email.
